# Track Auto Chess verification map

The public Next.js viewer is the runnable product surface on Linux. Use the smallest guide that covers the change:

- `player-lookup.md` — home-page Steam profile lookup and validation.
- `entity-browser.md` — Units, Items, and their committed-content detail pages.
- `synergy-browser.md` — Classes, Species, filters, and synergy details.
- `talents.md` — the courier talent tree and its linked relic context.
- `patch-notes.md` — latest and historical patch navigation.

Each guide starts from a control visible to a user and ends with a route or rendered-state assertion. Database-backed player results need configured Supabase credentials; the other mapped flows render from committed content.
